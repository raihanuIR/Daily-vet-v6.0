NASA API Data Flow

How real-time satellite data reaches your dashboard

1. Satellite Data Collection

NASA's satellites (like SMAP, GPM, and MODIS) orbit the Earth and continuously capture raw weather, soil moisture, rainfall, and vegetation data.

2. NASA POWER Processing

The raw data is sent to the NASA POWER server. Here it is cleaned, formatted into JSON, and stored in 0.5-degree grid cells so our app can easily read it.

3. API Request (Every 3 Hours)

DailyVet's system automatically sends an HTTP request to the NASA API using your district's coordinates. The API responds with the latest JSON data.

4. Engine Calculations

Our climate engine takes the raw JSON numbers (like Temperature and Humidity) and runs algorithms to calculate THI, Flood Risks, and Disease Outbreaks.

5. Visual Dashboard

Finally, the calculated data is displayed on your screen through visual cards, interactive maps, and risk alerts that you see on this dashboard.

Why does the time change? Satellites collect data at different intervals. NASA POWER updates every 3 hours, while GPM Radar updates every 30 minutes. The dashboard fetches data based on these specific API refresh cycles.
